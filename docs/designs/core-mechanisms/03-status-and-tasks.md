#### 3.1.1 变更档位字段

`变更档位` 是变更级状态文件的必填字段，取值为 `{轻量|标准|完整}`，决定后续各阶段的执行轮次、审查形态与产出深度。

| 写入/更新时机 | 责任 Skill | 写入内容 |
|--------------|-----------|---------|
| SPLIT 之后初判 | kflow-explore | 按「变更类型 + 功能点数」映射的初判档位（或用户在确认环节覆盖后的档位） |
| DIVIDE 之后复核 | kflow-design | 完整影响范围分数公式复核结果；仅允许升档，禁止降档 |

> **缺省回退**: 变更级 `.status.md` 基本信息中不含 `变更档位` 字段时（如历史变更），系统 SHALL 按 `完整` 档确定轮次与审查形态。`完整` 档等价于历史行为，是唯一无行为变化的缺省值。
>
> **档位判定公式与阈值** 参见 `docs/designs/skills/kflow-explore.md`（初判映射）与 `docs/designs/skills/kflow-design.md`（完整公式复核）；轮次取值参见 `07-agent-model.md` §15 与 §16。

#### 3.1.2 阶段适用性声明

`阶段适用性声明` 是变更级状态文件在 `变更档位 = 轻量` 时的条件性字段区，逐阶段记录测试阶段的适用性判定结果与判定依据，使「因不适用而跳过」与「遗漏产物」可区分。

| 维度 | 规则 |
|------|------|
| 适用对象 | 仅 `接口单元测试`、`E2E测试`、`集成测试` 三个阶段 |
| 生成时机 | kflow-design 完成 DIVIDE 步骤之后 |
| 写入位置 | 变更级 `.status.md` 的「阶段适用性声明」区 |
| 判定来源 | `detailed-design.md` 的接口设计章节与「跨子变更接口契约」子章节；`functional-designs/index.md` 的功能点类型与页面/组件/路由信息 |
| 保守回退 | 任一判定依据产物不存在、格式不符或字段缺失时，该阶段 SHALL 判定为 `✅ 适用`（失败方向偏向执行） |
| 缺省处理 | 声明区缺失（如历史变更或非轻量档）时，三个阶段 SHALL 全部按适用处理 |
| 档位隔离 | `标准` 与 `完整` 档 SHALL NOT 生成该声明区，阶段集合维持既有规则不变 |

> **裁剪合法性的唯一凭证**: 下游门控（进入测试阶段、进入集成测试、归档前最终覆盖检查）判定某阶段为合法跳过时，MUST 以本区的判定依据为准。无声明依据的 `⏭️` 一律阻塞，不区分来源。
>
> 阶段的判定条件与四态判定矩阵参见 `04-gates-and-transitions.md` §5.4；覆盖追溯矩阵的 `⏭️` 列处理参见 §5.4.3。
