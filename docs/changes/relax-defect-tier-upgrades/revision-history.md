# 修订记录历史 — relax-defect-tier-upgrades

> 本文件承接本次变更中按「文档头部仅保留最近 3 条修订记录」规则移出的历史条目。常规读取不加载本文件。

## references-src/state-values.md

> **v1.1.0**: 新增 §4「变更档位」字段定义——变更级 `.status.md` 基本信息的必填字段，驱动各阶段的审查形态与产出深度。
>
> **v1.2.0**: 新增 §5「阶段适用性声明」字段定义——轻量档下测试阶段的适用性判定与产物裁剪，含四态判定、保守回退与升档失效规则。
>
> **v1.3.0**: 审查终止模型改为固定单轮——档位语义收敛为「审查形态与产出深度」，SHALL NOT 决定轮数；§4 表格的「审查轮数」行与档位语义注同步；新增 §6「阶段耗时与轮次遥测字段」——变更级 `.status.md` 的两个遥测区字段定义。

## references-src/gates.md

> **v3.0.0**: 审查终止模型改为**固定单轮**——§1.3 自审记录判定由「自审报告份数 ≥ 1，无上限」改为「`self-reviews/{phase}/report.md` 存在」（固定一份、不按轮次编号）；Gate 2、归档门控与中断恢复产物完整性验证门控的终止判定改用**终止结果**字段的新取值（`验证通过` / `验证发现问题({N})` / `执行完成` / `定向重验失败` / `停滞`）；编码与详细设计的完成判定移除轮次相关前提。**签署清单结构、打假契约与终止结果的权威定义见 `signed-checklist-verification` 能力；执行类阶段验收见 `agent-iteration-execution` 能力。**
>
> **v2.0.0**: 审查终止模型调整——自审记录判定收敛为单条规则（§1.3）；归档门控与中断恢复产物完整性验证门控的终止判定由枚举旧终止原因改为按**终止结果**字段判读；Gate 2 自审记录检查按该规则简化；代码审查门控移除轻量档的单轮限制。
>
> **v1.2.0**: 新增 §1.2「阶段适用性声明与四态判定」——轻量档裁剪阶段的门控判定矩阵与无依据跳过的阻塞规则；进入接口单元测试/E2E测试/集成测试/归档四个门控新增裁剪分支。
>
> **v1.1.0**: 门控按变更档位分支——进入计划门控（Gate 2）按三档检查审查产物，代码审查门控新增轻量档单 Agent 判定。新增「变更档位」字段的透传与校验要求。
