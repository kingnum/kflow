# defect-strike-limit Specification

## Purpose

定义子变更级缺陷修复的三次尝试上限机制，防止无限自动循环，并规定修复尝试上限（内层，单用例）与迭代收敛终止（外层，轮数由收敛决定）之间的层级关系，与集成测试的「三回合架构评估」保持一致。

## Requirements

### Requirement: 子变更修复三次尝试上限

系统 SHALL 在子变更级缺陷修复循环中对同一失败限制最多 3 次自动修复尝试，第 3 次失败后 SHALL 升级到用户决策。

#### Scenario: 首次修复尝试
- **WHEN** 子变更测试失败且为首次尝试修复
- **THEN** 系统分析根因并按二分法分类
- **AND** 采用针对性修复方案

#### Scenario: 第二次修复尝试
- **WHEN** 子变更同一测试用例首次修复后仍然失败
- **THEN** 系统 SHALL 采用替代方案（不同工具或方法）
- **AND** 不得重复首次尝试的相同方案

#### Scenario: 第三次修复尝试
- **WHEN** 子变更同一测试用例第二次修复后仍然失败
- **THEN** 系统 SHALL 重新审视问题假设，考虑更广泛的替代方案
- **AND** 不得重复前两次尝试的方案

#### Scenario: 第三次失败后升级
- **WHEN** 子变更同一测试用例三次修复尝试均失败
- **THEN** 系统 SHALL 停止自动修复循环
- **AND** SHALL 使用 AskUserQuestion 升级用户，提供三个选项：保留当前状态 / 跳过该功能点 / 触发设计阶段回退
- **AND** SHALL 在修复报告中记录三次尝试的方案和失败原因

#### Scenario: 不同测试用例独立计数
- **WHEN** 子变更内有多个测试用例失败
- **THEN** 系统 SHALL 对每个测试用例独立计数尝试次数
- **AND** 一个用例达到上限不影响其他用例的正常修复

#### Scenario: 根因变更重置计数
- **WHEN** 修复过程中根因分类发生变更（如从实现错误变更为设计错误）
- **THEN** 系统 SHALL 重置尝试计数
- **AND** 按新的根因分类重新开始修复流程

### Requirement: 3 次修复上限与收敛终止的层级关系

系统 SHALL 在缺陷修复阶段并行维护两个独立指标：3 次修复尝试上限（内层，单用例上限）与迭代收敛终止（外层，轮数由收敛实际发生在第几轮决定，下限 1 轮，SHALL NOT 预置或受限于任何档位轮数上限）。两者独立运作，不互相替代。迭代达成收敛终止条件（最近一轮为见证轮）时 SHALL 结束并写入终止结果 `收敛`；命中不收敛判定时 SHALL 结束并写入终止结果 `未收敛`。

#### Scenario: 收敛循环内嵌 3 次修复上限

- **WHEN** 缺陷修复阶段 Agent 迭代子代理执行第 N 轮
- **AND** 某测试用例在第 N 轮中修复失败
- **THEN** Agent SHALL 遵循 3 次修复尝试上限规则进行修复
- **AND** 无论该用例修复结果如何，Agent 继续完成当前轮次其他工作
- **AND** 当前轮次完成后，若未达成见证轮且未命中不收敛判定，Agent 进入第 N+1 轮

#### Scenario: 3 次上限触发不终止轮次迭代

- **WHEN** 第 N 轮中某测试用例 3 次修复尝试均失败（触发 3 次上限）
- **THEN** Agent 升级用户决策（保留 / 跳过 / 回退）
- **AND** 升级用户不终止当前轮次——Agent 继续处理其他未触发上限的问题
- **AND** 当前轮次完成后继续下一轮（若未达成见证轮且未命中不收敛判定）
- **AND** 已触发上限的用例在后续轮次中标记为「用户决策中」，不再尝试修复

#### Scenario: 所有用例均触发上限时的处理

- **WHEN** 某轮次中所有失败用例均已触发 3 次上限
- **THEN** Agent 确认无更多可执行工作
- **AND** 该轮同时满足零修改、零新发现且报告证明全部用例已完成全量遍历时，SHALL 构成见证轮
- **AND** 见证轮成立时 SHALL 终止迭代并写入终止结果 `收敛`，SHALL NOT 为凑轮数而继续
- **AND** 该轮 SHALL 标注「所有问题已升级用户决策，无可修复项」

#### Scenario: 3 次上限与收敛终止的计数器独立

- **WHEN** Agent 迭代子代理执行缺陷修复
- **THEN** 迭代轮次（`执行轮次: N 轮`）约束整体迭代循环，其结束由收敛决定
- **AND** 修复尝试计数（每用例独立）约束单用例修复次数（上限 3 次）
- **AND** 两个计数器独立递增，互不干扰
