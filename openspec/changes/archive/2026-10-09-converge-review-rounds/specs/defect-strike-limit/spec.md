# Spec Delta

## ADDED Requirements

### Requirement: 修复尝试上限与轮次上限的层级关系

系统 SHALL 在缺陷修复阶段并行维护两个独立指标：迭代轮次（外层循环，上限由变更档位决定：`轻量` 1 / `标准` 3 / `完整` 5，下限 1）和 3 次修复尝试上限（内层单用例上限）。两者独立运作，不互相替代。迭代达成收敛终止条件（最近一轮为见证轮）时 SHALL 提前结束。

#### Scenario: 轮次上限内嵌3次修复上限

- **WHEN** 缺陷修复阶段 Agent 迭代子代理执行第 N 轮（N ∈ [1, 轮次上限]）
- **AND** 某测试用例在第 N 轮中修复失败
- **THEN** Agent 遵循 3次尝试上限规则进行修复（上限）
- **AND** 无论该用例修复结果如何，Agent 继续完成当前轮次其他工作
- **AND** 当前轮次完成后递增轮次计数器，进入第 N+1 轮（若未达收敛或上限）

#### Scenario: 3次上限触发不终止轮次迭代

- **WHEN** 第 N 轮中某测试用例 3次修复尝试均失败（触发3次上限）
- **THEN** Agent 升级用户决策（保留/跳过/回退）
- **AND** 升级用户不终止当前轮次——Agent 继续处理其他未触发上限的问题
- **AND** 当前轮次完成后继续下一轮（若未达收敛或上限）
- **AND** 已触发上限的用例在后续轮次中标记为「用户决策中」，不再尝试修复

#### Scenario: 所有用例均触发上限时的处理

- **WHEN** 某轮次中所有失败用例均已触发3次上限
- **THEN** Agent 确认无更多可执行工作
- **AND** 该轮同时满足零修改且报告证明全部用例已完成全量遍历时，SHALL 构成见证轮
- **AND** 见证轮成立时 SHALL 终止迭代，SHALL NOT 强制递增计数器至轮次上限
- **AND** 该轮 SHALL 标注「所有问题已升级用户决策，无可修复项」

#### Scenario: 轮次上限与3次上限的计数器独立

- **WHEN** Agent 迭代子代理执行缺陷修复
- **THEN** 轮次计数器（执行轮次: N/{上限}）约束整体迭代循环次数（上限由档位决定）
- **AND** 修复尝试计数（每用例独立）约束单用例修复次数（上限）
- **AND** 两个计数器独立递增，互不干扰

## REMOVED Requirements

### Requirement: 修复尝试上限与迭代轮次的层级关系

**Reason**: 外层指标由「10 轮迭代（下限）」改为「档位轮次上限」，并移除「不因无工作而跳过轮次——10 轮计数器仍须递增至 10/10」（该行为由见证轮收敛终止取代）。

**Migration**: 由新增的「修复尝试上限与轮次上限的层级关系」替代。
