# Spec Delta

## REMOVED Requirements

### Requirement: 终止前复检轮触发条件

**Reason**: 复检轮的触发条件是「到达终止点**且**累积未复核修复清单非空」，而清单非空只能出现在「执行轮次 = 档位轮次上限」这条路径上。轮次上限废除后，终止点只剩「最近一轮为见证轮」一种，而见证轮候选按复核义务必须逐项复核清单内全部条目——收敛即意味着清单为空，复检轮因此成为不可达的死代码。

**Migration**: 复核义务上提为见证轮定义的第 (d) 项条件（见 `convergence-driven-repetition` 能力的「累积未复核修复清单与复核义务」Requirement）。成功终止路径由见证轮自带复核保证；不收敛路径直接升级用户，不再插入「只验证不修复」的轮次——保留它会引入「复检轮自身未通过」的二次兜底，而无上限模型下该二次兜底无处安放。

### Requirement: 复检轮预算与档位解耦

**Reason**: 该 Requirement 规定复检轮不消耗档位轮次预算、最多追加 1 轮、不计入 `执行轮次` 字段——全部以「档位轮次预算」与 `{N} / {上限}` 字段格式为前提，两者均随上限废除。

**Migration**: 随复检轮机制一并移除；`执行轮次` 字段改为 `{N} 轮`（见 `round-counter` 能力）。

### Requirement: 复检轮的复核范围

**Reason**: 「逐项复核自审循环开始以来全部尚未通过独立复核的修复」这一复核范围规则实质有效，但其载体（复检轮这一独立轮次）被移除。

**Migration**: 复核范围作为见证轮候选的复核义务保留，迁移至 `convergence-driven-repetition` 的「累积未复核修复清单与复核义务」Requirement（清单跨轮累加、已复核条目移出列表、不得仅复核最后一轮的修复）。

### Requirement: 复检轮通过判据

**Reason**: 复检轮的通过判据本就是「构成见证轮」——即在见证轮三项条件之外附加「清单内全部条目逐项复核通过」。该附加条件已上提为见证轮定义的正式第 (d) 项，独立判据不再存在。

**Migration**: 迁移为见证轮的第 (d) 项条件；「未证明全量遍历的复检轮不得通过」的反空转条款由见证轮第 (c) 项条件覆盖。

### Requirement: 复检轮结果写入

**Reason**: 终止原因取值 `收敛（复检轮）` 与 `达上限` 随复检轮与上限一并废除；复检轮专用报告文件不再产出。

**Migration**: 终止结果改由 `convergence-driven-repetition` 的「终止结果写入」Requirement 承载，取值二值 `收敛` / `未收敛`；各阶段既有审查报告目录的命名规则不变，只是不再有 `round-recheck.md` 一类复检轮报告。
